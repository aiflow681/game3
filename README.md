【游戏名称】
NEOSHIFT | 超级大冒险

【游戏介绍】
这是一款H5原生开发的复古风格跑酷冒险游戏。游戏采用经典的像素艺术风格，玩家需要控制角色在不断生成的平台上跳跃前进，收集金币，躲避敌人，挑战更远的距离。游戏支持桌面端和移动端双平台，画面精美，操作流畅，充满复古游戏的魅力。

【玩法说明】
游戏规则：

玩家需要控制左右移动和跳跃
平台会不断生成，玩家需要跳跃到下一个平台上
掉落到屏幕外会扣除生命值，生命值耗尽游戏结束
收集金币可以增加分数，连续收集有连击加成
躲避敌人（黑色圆球），碰到会扣除生命值
游戏距离越远，难度越高，平台间隔会增大
道具说明：

金币（金色圆形）：收集后获得100分，连续收集有连击加成
治疗道具（绿色）：恢复30点生命值
敌人（黑色圆球）：碰到会扣除25点生命值，需要躲避
操作方式：

【桌面端操作】

方向键 ← / A键：向左移动
方向键 → / D键：向右移动
空格键 / W键 / ↑键：跳跃（支持二段跳）
可以在空中调整方向
【移动端操作】
横屏模式：

点击左下角 ← 按钮：向左移动
点击左下角 → 按钮：向右移动
点击右下角 ⇈ 按钮：跳跃（支持二段跳）
竖屏模式：

点击底部 ← 按钮：向左移动
点击底部 → 按钮：向右移动
点击底部 ⇈ 按钮：跳跃（支持二段跳）
游戏目标：
在生命值耗尽之前，跑得越远越好，收集更多金币，挑战最高分和最远距离！

游戏特色：

复古像素风格，经典8位游戏画面
流畅的物理引擎，真实的跳跃手感
支持二段跳，可以在空中再次跳跃
动态难度系统，游戏越往后越有挑战性
连击系统，连续收集金币获得额外加分
完善的评级系统（S/A/B/C），根据得分评定等级
自动保存点系统，掉落后可以从最近的平台重生
粒子特效，增强游戏视觉效果
复古音效系统，跳跃、收集、受伤都有音效反馈
Tips：

掌握二段跳的时机，可以跳得更远
注意观察下一个平台的位置，提前调整方向
连续收集金币可以获得连击加成，分数更高
生命值低时优先寻找治疗道具
移动端建议使用横屏模式以获得更好的游戏体验
左上角显示当前金币数、分数和生命值
右上角显示当前冒险距离
游戏结束后会显示最终得分、距离、金币数和游戏时长
评级标准：

S级：得分超过20000分
A级：得分超过10000分
B级：得分超过5000分
C级：得分低于5000分
【技术介绍】
HTML5原生开发，主要语言是JavaScript，使用了Canvas 2D渲染技术。

核心技术：

Canvas 2D API：用于游戏画面渲染，支持高性能图形绘制
自定义物理引擎：实现重力、摩擦力、跳跃等物理效果
粒子系统：实现爆炸、收集等视觉特效
Web Audio API：实现复古风格的音效系统
响应式设计：自动适配桌面端、移动端横屏和竖屏模式
动态难度系统：根据游戏进度自动调整难度
状态管理系统：管理游戏状态、玩家数据、平台生成等
技术特点：

60 FPS流畅运行
像素化渲染（image-rendering: pixelated）
支持键盘和触摸双输入模式
智能设备检测，自动切换控制方式
虚拟控制器UI，专为移动端优化
方向管理器，支持横竖屏自动适配
相机跟随系统，平滑跟踪玩家位置
对象池管理，优化内存使用
碰撞检测优化，精确的物理判定
游戏优化：

移动端坐标转换：精确处理触摸坐标
平台动态生成：根据屏幕大小和难度生成平台
渲染优化：只绘制可见区域的对象
内存管理：及时清理超出屏幕的对象
事件优化：防止重复触发，避免性能问题
自适应缩放：根据设备类型和方向自动调整画面
兼容性：

支持Chrome、Safari、Firefox、Edge等现代浏览器
支持iOS和Android移动设备
支持触摸屏和鼠标操作
支持横屏和竖屏模式
最低要求：支持HTML5 Canvas和ES6的浏览器
